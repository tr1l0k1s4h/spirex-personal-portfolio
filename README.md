# Triloki Sah — Personal Portfolio

A simple responsive portfolio for SpireX Foundation Advanced Session, Task 1. It uses plain HTML, CSS, and vanilla JavaScript, with no packages or build step.

## Open the project

1. Extract the ZIP.
2. Open index.html in a current browser.
3. Check the layout at desktop and phone widths.

The page works locally without a server or network connection.

## Features

- Light and dark themes saved in the browser.
- Mobile navigation with Escape key support.
- Project filters for all projects, web, and Python.
- A reading progress bar and back-to-top button.
- Email link and copy button, plus LinkedIn and GitHub links.
- Responsive layout and reduced-motion support.

## Contact details

The CONTACT object near the top of script.js controls which contact links appear. Review these details before sharing the site. Leave a value empty to hide its link. The email copy button appears only when an email value is present.
